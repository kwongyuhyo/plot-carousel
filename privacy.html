PLOT Magazine 개인정보처리방침

시행일 2026-10-11 · 운영 Pluto System (권규효) · 문의 plotmusiclive@gmail.com

무엇을 하는 앱인가

PLOT Magazine은 음악 매체 PLOT의 내부 제작 도구입니다. PLOT 운영진이 만든 숏폼 영상을 PLOT 자체 유튜브 채널에 올리고, 올린 영상의 상태를 확인하는 데만 Google 계정 연결(YouTube Data API)을 사용합니다. 일반 사용자를 대상으로 한 서비스가 아닙니다.

어떤 정보를 쓰는가

  • PLOT 채널 계정의 OAuth 인증 토큰 — 운영진 컴퓨터 안에만 저장되며 외부 서버로 보내지 않습니다.
  • PLOT 채널의 영상 목록과 업로드 결과 — 업로드 확인 용도로만 씁니다.

다른 사람의 개인정보, 시청 기록, 연락처 등은 요청하거나 수집하지 않습니다.

공유와 보관

Google에서 받은 정보를 제3자에게 판매·공유·이전하지 않으며, 광고에 쓰지 않습니다. Google API 서비스로 받은 정보의 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.

연결 끊기

언제든 Google 계정 → 타사 연결에서 PLOT Magazine의 접근 권한을 해제할 수 있습니다. 해제하면 저장된 토큰은 더 이상 쓸 수 없고, 요청 시 운영진 컴퓨터의 토큰도 지웁니다.

English summary

PLOT Magazine is an internal publishing tool of the music outlet PLOT, operated by Pluto System. It uses the YouTube Data API only to upload short videos to PLOT's own YouTube channel and to check upload status. OAuth tokens are stored only on the operator's computer and are never sold, shared, transferred to third parties, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. Contact: plotmusiclive@gmail.com
